LAN sharing

Type @, pick people, send. No more one message per person.

Select a lot, press Ctrl+Shift+Enter and mention colleagues or a whole team. Hopper finds everyone running it on the network by name — no IP addresses, no shared folders to dig through.

  • Direct PC-to-PC over the office network: encrypted, up to four parallel streams, resumes after a dropped connection, every file checksum-verified.
  • Colleague offline? It waits in their server inbox and arrives the moment their Hopper starts.
  • An office bot DMs each person in Zoho Cliq: “Asha sent you 3 files — Lot 07 for back-check”.
  • Drop files on a person in the sidebar to send them. Received files land in a tidy Inbox.
Archives

Zip in one keystroke. Open any archive like a folder.

Ctrl+Alt+Z zips the selection next to it with a sensible name, using the bundled 7-Zip on every core. Keep presets for the archives you make every day.

  • Presets: store-speed, balanced, smallest 7z, 20 MB email parts, password (AES-256), RAR through WinRAR.
  • Browse zip, 7z, rar, tar and iso as folders; drag files out, add or delete inside.
  • Smart extract: one top-level folder? No more “Lot 07\Lot 07”.
Copy, move, paste

A transfer queue you can trust on a network drive.

Every copy, move, zip, extract and share goes into one queue with live speed and time left. Keep working — nothing locks the window.

  • Pause, resume and cancel; one conflict question with “do this for all”; optional checksum verify.
  • Moves within a drive are instant. Flaky shares are retried automatically.
  • Copy to / Move to remembers your destinations; pin the ones you use every day.
  • Shares Explorer's clipboard both ways, and drags files out to Explorer, Outlook or Cliq.
Built for drawing offices

Lots, transmittals, revisions and PDFs — without leaving the folder.

Package a lot in one dialog: check every name against your convention, see the revisions Hopper found, write the transmittal as Excel and PDF, zip it and share it.

  • Revision-aware view groups _RevA / _RevB / _Rev0 under the latest — and flags orders it can't decide instead of guessing.
  • PDF toolkit: merge, split, extract, rotate and reorder pages.
  • Folder templates create a project or lot tree in one click. Rules live in one shared office config.

Office setup

Five minutes for the whole office.

  1. Install Hopper on each PC. Per-user, no admin, updates itself.
  2. Settings → Office: point at a shared config file, generate the office key, save to server.
  3. Settings → Sharing: allow through the firewall and fill in your name and Zoho email.
  4. Optional: add the Cliq bot, groups, folder templates and naming rules.

Questions

Good to know

Do files leave our network?

No. Files go directly between office PCs over TLS with your office key, or through the server folder you choose. Only the notification text is sent to Zoho Cliq, and only if you turn the bot on.

What happens if a colleague's PC is off?

The share is copied to their folder in the server inbox. When their Hopper starts, it moves the files into their Inbox and notifies them.

Does it replace Windows Explorer?

It can open folders by default (Settings → Advanced), and it shares Explorer's clipboard, context menu, icons and thumbnails, so you can use both side by side.

Why does Windows warn the first time I install it?

The installer is not code-signed yet, so SmartScreen asks for confirmation. Each release lists SHA-256 checksums so you can verify the download.

Is it free?

Yes — Hopper is open source under the MIT licence.
